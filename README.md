# ENKI ERP — نموذج الموجودات الثابتة (Clickable Mock)

نموذج تفاعلي لوحدة **الموجودات الثابتة** بواجهة ENKI ERP (عربي، من اليمين لليسار). جميع البيانات تجريبية وتُحفظ في متصفحك (localStorage)، ويمكن إعادة تعيينها من «إعدادات الوحدة».

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح http://localhost:5173 . للنسخة النهائية: `npm run build` (المخرجات في `dist/` وتعمل من أي استضافة ثابتة).

## الشاشات

| الشاشة | المسار | ما يمكن تجربته |
|---|---|---|
| لوحة المعلومات | `#/` | مؤشرات، القيمة حسب الفئة، الأصول حسب الحالة، تنبيهات، آخر الحركات |
| سجل الأصول | `#/assets` | تبويبات الحالة، تصفية بالفئة/المجموعة/الفرع، مجاميع |
| بطاقة الأصل | `#/assets/:id` | إنشاء مسودة، رسملة، جدول الإهلاك، إيقاف/استئناف، إعادة تقييم، نقل، بيع، استبعاد، تعديل العمر، سجل الأحداث |
| دورات الإهلاك | `#/runs` | محاكاة ← ترحيل بقيد واحد ← عكس |
| حركات الأصول | `#/transactions` | سجل كل الأحداث مع القيد المحاسبي |
| التقارير | `#/reports` | سجل الأصول بتاريخ، توقّع الإهلاك، حسب الموقع/العهدة، الاستبعادات، مطابقة دفتر الأستاذ |
| فئات الأصول | `#/classes` | الطريقة، العمر، الدورية، التحاصص، الحسابات (مع التحقق من قابليتها للترحيل) |
| المواقع / المجموعات | `#/locations`, `#/groups` | شجرة المواقع، المجموعات التنظيمية |
| الصلاحيات والترقيم | `#/settings` | مصفوفة الأدوار × الصلاحيات، أنواع الوثائق، إعادة تعيين البيانات |

بدّل الدور من قائمة المستخدم أعلى الشاشة لترى أثر الصلاحيات على الأزرار.

سيناريو عرض مقترح: افتح «شاشات عرض تفاعلية Samsung Flip» (مسودة) ← رسملة ← دورات الإهلاك ← دورة جديدة لتشرين الأول ← محاكاة ← ترحيل ← تبويب القيد المحاسبي ← التقارير ← مطابقة دفتر الأستاذ.
