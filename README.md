# ENKI ERP — نموذج الموجودات الثابتة (Clickable Mock)

نموذج تفاعلي لوحدة **الموجودات الثابتة** بواجهة ENKI ERP (عربي، من اليمين لليسار). جميع البيانات تجريبية وتُحفظ في متصفحك (localStorage)، ويمكن إعادة تعيينها من «إعدادات الوحدة».

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح http://localhost:5173 . للنسخة النهائية: `npm run build` (المخرجات في `dist/` وتعمل من أي استضافة ثابتة).

## الشاشات

| الشاشة | المسار | ما يمكن تجربته |
|---|---|---|
| لوحة المعلومات | `#/` | مؤشرات، التوزيع حسب الفئة والفرع، تنبيهات، آخر النشاطات |
| سجل الموجودات | `#/assets` | بحث وتصفية، مجاميع، فتح البطاقة |
| بطاقة الموجود | `#/assets/:id` | إنشاء/تعديل، تفعيل، جدول الاستهلاك المتوقع، الحركات، السجل، ملصق باركود |
| فئات الموجودات | `#/categories` | طريقة الاستهلاك والعمر الإنتاجي والحسابات المحاسبية |
| المواقع | `#/locations` | المواقع والفروع |
| احتساب الاستهلاك | `#/depreciation` | احتساب شهري تلقائي، تعديل الأقساط، ترحيل، القيد المحاسبي |
| نقل الموجودات | `#/transfers` | نقل الموقع وصاحب العهدة |
| إعادة التقييم | `#/revaluations` | القيمة العادلة وفائض/خسارة التقييم |
| الاستبعاد والبيع | `#/disposals` | بيع/إتلاف/تبرع مع احتساب الربح أو الخسارة |
| الصيانة | `#/maintenance` | أوامر صيانة، رسملة التكلفة |
| التقارير | `#/reports` | سجل حسب الفئة، حركة الموجودات، العهد، الضمان |
| إعدادات الوحدة | `#/settings` | الإعدادات العامة وإعادة تعيين البيانات |

دورة المستندات: **مسودة ← مُرحّل ← ملغى**. الترحيل يحدّث بطاقات الموجودات وينشئ القيد المحاسبي (يظهر في تبويب «القيد المحاسبي»).

## التقنيات

Vite + React 18 + TypeScript + Tailwind CSS + lucide-react، بدون خادم خلفي.
