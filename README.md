# ENKI ERP — نموذج الموجودات الثابتة (Clickable Mock)

نموذج تفاعلي لوحدة **الموجودات الثابتة** بواجهة ENKI ERP (عربي، من اليمين لليسار). جميع البيانات تجريبية وتُحفظ في متصفحك (localStorage)، ويمكن إعادة تعيينها من «إعدادات الوحدة».

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح http://localhost:5173 . للنسخة النهائية: `npm run build` (المخرجات في `dist/` وتعمل من أي استضافة ثابتة).

## الشاشات

| الشاشة | المسار | ما يمكن تجربته |
|---|---|---|
| لوحة المعلومات | `#/` | مؤشرات، القيمة حسب الفئة، الأصول حسب الحالة، تنبيهات، آخر الحركات |
| سجل الأصول | `#/assets` | تبويبات الحالة (ومنها الملغى)، تصفية، «من سطر فاتورة شراء» ينشئ N أصلاً |
| بطاقة الأصل | `#/assets/:id` | رسملة، إلغاء، تراجع عن الرسملة، إيقاف/استئناف، إعادة تقييم، هبوط قيمة، إضافة لاحقة، تخفيض اقتناء، إهلاك يدوي، تعديل العمر، نقل موقع/عهدة، نقل مركز كلفة بتاريخ سريان، بيع/استبعاد مع إهلاك حتى التاريخ، عكس البيع؛ تبويب «بطاقة الأصل» بأرصدة جارية |
| دورات الإهلاك | `#/runs` | محاكاة ← ترحيل بقيد واحد ← عكس؛ قواعد عدم التداخل وعدم الفجوات وLIFO |
| حركات الأصول | `#/transactions` | سجل التدقيق مع نوع الوثيقة والقيود (ومنها قيود الوحدات الأخرى للمطابقة) |
| الصيانة | `#/maintenance` | أوامر وقائية/علاجية/فحص؛ الرسملة تُرحَّل كإضافة لاحقة (240) |
| التقارير السبعة | `#/reports` | السجل بأي تاريخ سابق، جدول الحركة (عمود «غير مفسَّر» = 0)، بطاقة الأصل، توقّع الإهلاك، حسب الموقع/العهدة، الاستبعادات، مطابقة الأستاذ بنفس التاريخ |
| الإعدادات | `#/classes`, `#/locations`, `#/groups`, `#/settings` | أنواع الأصول والحسابات لكل مجال، الحدود، القرارات المفتوحة §12، الصلاحيات، أنواع الوثائق 230–242 |

بدّل الدور من قائمة المستخدم أعلى الشاشة لترى أثر الصلاحيات على الأزرار.

سيناريو عرض مقترح: «شاحنة إيسوزو NPR» ← إجراءات ← بيع (لاحظ الإهلاك حتى التاريخ) ← عكس البيع ← دورات الإهلاك ← دورة تشرين الأول ← ترحيل ← محاولة عكس أيلول (ترفضها قاعدة LIFO) ← التقارير ← جدول الحركة.
